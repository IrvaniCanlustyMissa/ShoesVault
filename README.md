# shoes_vault

A new Flutter project.
ShoesVault 👟
ShoesVault adalah aplikasi mobile berbasis Flutter yang dirancang untuk membantu pengguna mendata koleksi sepatu pribadi mereka secara terorganisir. Aplikasi ini dibuat sebagai pemenuhan tugas Mini Project Flutter.

Fitur Utama:
Tambah Data (Create): Menambahkan merk, ukuran, dan tahun rilis sepatu melalui form.

Tampilkan Data (Read): Melihat daftar koleksi sepatu dalam bentuk list yang dinamis.

Edit Data (Update): Memperbarui informasi sepatu yang sudah ada di daftar.

Hapus Data (Delete): Menghapus data sepatu dari koleksi.

Persyaratan Teknis
Aplikasi ini telah memenuhi kriteria tugas:

Memiliki minimal 3 TextField dalam satu form (Merk, Ukuran, Tahun).

Menggunakan navigasi antar halaman (Multi Page Navigation).

Implementasi fungsionalitas Update/Edit data sebagai nilai tambah.

Widget yang Digunakan:
Scaffold: Sebagai kerangka utama halaman.

ListView.builder: Untuk menampilkan list data koleksi secara efisien.

TextField: Untuk menerima input teks dari pengguna.

ElevatedButton: Tombol untuk memproses simpan data.

Navigator: Untuk berpindah dari halaman utama ke halaman form dan sebaliknya.

StatefulWidget & setState: Untuk manajemen status aplikasi secara sederhana dan reaktif.
